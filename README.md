# Звенко

CRM для малого бизнеса, в которой всё общение с клиентами — в одном окне: мессенджеры, звонки, почта, заявки с сайта. Карточку заполняет система, менеджер только подтверждает.

> **Статус:** ранняя разработка (pre-alpha). Продуктом пока нельзя пользоваться.

## Принципы

- **Безопасность с первого коммита.** Изоляция данных компаний на трёх уровнях: код, политики PostgreSQL (RLS), автотесты. Сканеры секретов и уязвимостей в CI.
- **Скорость.** Права проверяются одним условием в запросе к базе, бюджеты производительности проверяются в CI.
- **Данные клиентов из РФ хранятся в РФ.**
- **Открытые компоненты, внешние сервисы — за адаптерами.** Поставщика можно сменить без переписывания продукта.

## Быстрый старт

Нужны [mise](https://mise.jdx.dev) и Docker.

```sh
mise install    # Node.js, pnpm и инструменты — версии из mise.toml
pnpm install
pnpm dev:up     # PostgreSQL, Valkey, S3, почта + git-хуки
```

Проверки — те же, что в CI:

```sh
pnpm format:check && pnpm lint && pnpm typecheck && pnpm test
```
